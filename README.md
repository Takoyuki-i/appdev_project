# CSPC Event Management System

## About the Project

The CSPC Event Management System is a web-based application developed as an academic project for Camarines Sur Polytechnic Colleges (CSPC). It aims to provide a platform for organizing and managing campus event-related information.

## Technologies Used

- **Node.js** – Runs the server-side JavaScript application.
- **Express.js** – Handles application routes and HTTP requests.
- **EJS** – Provides templates for rendering web pages.
- **CSS** – Styles the application's user interface.
- **JavaScript** – Supports application and client-side functionality.
- **MySQL** – Stores and manages application data.
- **bcrypt** and **bcryptjs** – Password-hashing libraries included in the project dependencies.

## Folder and File Descriptions

### `database/`
Contains the SQL file used to create and initialize the application's database.

### `login_and_signup/`
Contains project files related to the login and registration functionality.

### `node_modules/`
Contains the installed npm packages required by the application. It is generated by running `npm install` and normally should not be committed to Git.

### `public/`
Contains static assets used by the application.

- `css/` – Contains stylesheets for the user interface, including `index.css` and `login.css`.
- `images/` – Stores image assets, including the CSPC seal.
- `js/` – Contains client-side JavaScript files, including `admin.js`.

### `views/`
Contains EJS templates used to render the application's web pages.

- `admin.ejs` – Administrative interface.
- `dashboard.ejs` – Dashboard interface.
- `event_form.ejs` – Event form interface.
- `index.ejs` – Homepage.
- `login.ejs` – Login page.
- `register.ejs` – Registration page.

### `app.js`
The main application file responsible for configuring the Express server, database connection, middleware, and application routes.

### `.env`
An environment configuration file that is currently empty. The application does not automatically use this file unless it is configured to load its contents.

### `.gitignore`
Specifies files and folders Git should ignore.

### `package.json`
Contains project metadata, npm scripts, and dependencies.

### `package-lock.json`
Records the dependency versions used by npm to help maintain consistent installations.

### `README.md`
Documents the project, its structure, technologies, and setup instructions.

## Prerequisites

Before running the project, make sure you have installed:

- Node.js
- npm
- MySQL Server or MAMP with MySQL enabled
- Git

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Takoyuki-i/appdev_project.git
cd appdev_project
```

### 2. Install dependencies

```bash
npm install
npm install express ejs mysql2
npm install bcrypt
```

### 3. Set up the database

1. Start your MySQL server.
2. Create a database named `event_managementDB` if it does not already exist.
3. Import `database/event_managementdb.sql` into the database.
4. Make sure the database connection settings in `app.js` match your local MySQL host, port, username, and password.

The database contains the following tables:

- `accounts`
- `departments`
- `eventorganizer`
- `events`
- `venues`

### 4. Run the application

Start the server using:

```bash
node app.js
```

Once the server is running, open your browser and visit:

http://localhost:3001

## Development Notes

- Each team member should configure the database connection according to their local MySQL setup.
- Do not commit database passwords or other sensitive credentials to the repository.
- Import the SQL file when setting up the database for the first time.
- Test application features to verify that they work as intended.
